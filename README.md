# 🎨 CSS Changer Application

A simple and interactive web application that allows users to dynamically change CSS properties of an image using JavaScript and CSS variables.

## 📌 Project Description

This project is built using HTML, CSS, and JavaScript.
It demonstrates how to use CSS variables and JavaScript to update styles in real-time.

Users can control different properties of an image such as:

* Width
* Padding
* Border Radius
* Blur Effect
* Background Color

## 🚀 Features

* Real-time CSS updates
* Interactive sliders
* Clean and simple UI
* Beginner-friendly project

## 🛠️ Technologies Used

* HTML5
* CSS3 (CSS Variables)
* JavaScript (DOM Manipulation)

## 📂 How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in your browser
